# AI Life Copilot 
### Your Intelligent Everyday AI Assistant

AI Life Copilot is an AI-powered productivity and personal assistance platform designed to help users manage their daily activities, organize tasks, improve decision-making, and simplify digital life through the power of Generative AI.  

The project combines intelligent automation, personalized assistance, and modern AI technologies to create a smart companion capable of supporting users in productivity, planning, learning, and lifestyle management.

---

# 🌍 Why This Project?

In today’s fast-paced digital world, people struggle with:

- Managing tasks and schedules efficiently  
- Organizing personal and academic/work life  
- Information overload and decision fatigue  
- Lack of personalized AI assistance  
- Productivity loss due to scattered tools and workflows  

AI Life Copilot was created to solve these challenges by bringing multiple intelligent capabilities into a single AI-driven platform.

The goal is to make AI more practical, accessible, and useful for everyday life.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
